Задание:
1. Создайте новый проект на базе SpringMVC.
2. Ваше приложение должно обрабатывать запрос GET /about.
3. При переходе по URL/about должна открываться статическая страница "О нас".
4. Страница"О нас"должна содержать следующую информацию: название вашей вымышленной компании, краткое описание деятельности и список основных участников с их ролями.
5. Всю эту информацию вы можете придумать самостоятельно (создать html страницу с минимальной разметкой). Страница должна быть статической, то есть всю информацию вы заранее заносите в HTML-файл, а не получаете из базы данных или другого источника данных.
6. После создания приложения убедитесь, что при переходе по URL/about отображается страница "О нас" с корректной информацией.
В нашем случае страница http://localhost:8080/about
